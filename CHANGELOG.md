# Changelog

## 0.2.0 — 2026-08-09

- добавлен мастер создания полностью связанной сцены `90_CombatSandbox`;
- добавлены временный контроллер персонажа и орбитальная камера;
- добавлено сенсорное движение, вращение камеры и боевые кнопки;
- добавлены лёгкое комбо, тяжёлая атака, блок и два заряда рывка;
- добавлены единые расчёт урона, здоровье, броня, смерть и возрождение;
- добавлены три тренировочных врага;
- добавлен HUD здоровья и зарядов рывка;
- добавлены Edit Mode тесты расчёта урона;
- Starter Assets оставлен внешней бесплатной зависимостью.

## 0.1.0 — 2026-08-09

- создана бесплатная Unity 6.3 LTS основа;
- добавлены Bootstrap и реестр служб;
- добавлена машина состояний;
- добавлены раздельные файлы прохождения и постоянной расы;
- добавлены переходы сцен и маршрутизатор ввода;
- добавлен мастер структуры, сцен и Android-настроек;
- добавлены первые Edit Mode тесты и документация.
