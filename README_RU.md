# «Северные Земли XIV» — Unity-основа 0.2.0

Это первый технический этап бесплатной мобильной 3D Action RPG. Основа рассчитана
на **Unity 6.3 LTS**, **URP**, Android и бесплатный пакет **Starter Assets — ThirdPerson URP**.

## Что уже подготовлено

- чистое пространство игры `Assets/_NorthernLands`;
- Bootstrap и реестр постоянных сервисов;
- состояния игры: загрузка, меню, игра, пауза, диалог, инвентарь и смерть;
- отдельное сохранение прохождения с резервной копией;
- отдельный постоянный профиль выбранной расы;
- безопасная служба перехода между сценами;
- единый маршрутизатор ввода для клавиатуры, геймпада и мобильного HUD;
- `RaceDefinition` для хранения рас как данных;
- мастер создания папок и 19 стартовых сцен;
- Android-профиль: IL2CPP, ARM64, горизонтальный режим, API 26+;
- первые Edit Mode тесты;
- документы архитектуры и дорожная карта.
- автономная боевая песочница, создаваемая одной командой;
- временный персонаж-капсула до импорта модели Starter Assets;
- движение, вращение камеры и мобильный сенсорный HUD;
- лёгкое комбо из трёх ударов, тяжёлая атака, блок и два рывка;
- единые здоровье, броня, урон, смерть и возрождение;
- три простых тренировочных врага.

Это ещё не готовая игра: моделей, анимаций, законченной карты, инвентаря, квестов и
полноценного AI пока нет. Но минимальный бой уже можно запустить и проверить.

## Первый запуск

1. В Unity Hub установите Unity **6.3 LTS** с модулями:
   - Android Build Support;
   - Android SDK & NDK Tools;
   - OpenJDK.
2. Добавьте папку `NorthernLandsUnity` как существующий проект и откройте её.
3. Дождитесь окончания установки пакетов и компиляции.
4. В `Window → Package Manager → My Assets` найдите и импортируйте бесплатный
   `Starter Assets - ThirdPerson URP`.
5. Если Unity спросит про новый Input System, включите его и разрешите перезапуск.
6. Выполните по порядку:
   - `Tools → Northern Lands → 1. Create Project Folders`;
   - `Tools → Northern Lands → 2. Create Starter Scenes`;
   - `Tools → Northern Lands → 3. Apply Android Defaults`;
   - `Tools → Northern Lands → 4. Create Combat Sandbox`;
   - `Tools → Northern Lands → Validate Foundation`.
7. Переключите платформу на Android через `File → Build Profiles`.
8. Откройте `90_CombatSandbox` и нажмите Play. Эта сцена работает с временной
   капсулой даже до импорта Starter Assets.

## Управление в боевой песочнице

- ПК: `WASD` — ходьба, средняя кнопка мыши — камера;
- ЛКМ — лёгкая атака, ПКМ — тяжёлая атака;
- `Ctrl` — блок, `Space` — рывок;
- Android: левый джойстик, движение пальцем по правой части экрана и четыре кнопки.

## Важные правила

- Не редактировать исходники Starter Assets.
- Весь код игры хранить только внутри `_NorthernLands`.
- Связь с шаблоном выполнять через `Integrations/StarterAssets`.
- Не добавлять 45 рас сразу: сначала одна раса и законченный вертикальный срез.
- Новая система считается готовой только после проверки на Android.

Следующий этап: импортировать Starter Assets, заменить временную капсулу на персонажа
с Animator, связать боевые действия с анимациями и собрать первый Android development APK.

## Облачная сборка без локального ПК

Для Unity Build Automation добавлен pre-export метод
`NorthernLands.Editor.CloudBuildHooks.PreExport`. Он автоматически создаёт боевую
песочницу, применяет Android-настройки и делает её стартовой сценой перед облачной
сборкой. Подробная настройка описана в
`Documentation/CloudBuild/UnityBuildAutomation.md`.
