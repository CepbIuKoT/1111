# Известные ограничения

- Starter Assets не вложен в комплект: бесплатный пакет нужно импортировать владельцу
  проекта через Unity Package Manager.
- Сцены создаются мастер-командой после первой успешной компиляции.
- URP Render Pipeline Asset и профили Low/Medium/High ещё не настроены.
- Input Actions для боевых кнопок ещё не созданы и не привязаны.
- Боевая песочница использует временную капсулу без Animator и анимаций атак.
- Тренировочные враги двигаются напрямую и пока не используют NavMesh.
- Мобильный HUD ещё не учитывает Safe Area конкретных телефонов.
- Сборка Android не проверена в этой среде, потому что Unity Editor и Android SDK здесь
  отсутствуют.
- Формат сохранения пока покрывает только минимальные поля Foundation; перед добавлением
  инвентаря потребуется миграция версии 1 → 2.
