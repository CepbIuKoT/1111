# Адаптер Starter Assets

Папка предназначена только для связи игровых систем с бесплатным пакетом
`Starter Assets - ThirdPerson URP`.

Правила:

- исходники Starter Assets не редактировать;
- сам пакет хранить вне `_NorthernLands`, в своей стандартной папке;
- действия ввода привязать к `PlayerInputRouter`;
- новые боевые действия добавлять в собственный Input Actions asset игры;
- заменять контроллер только через адаптер, не через зависимости из игровых систем.

После импорта пакета первым делом проверяется его демо-сцена, затем персонаж
переносится в `90_CombatSandbox`.
