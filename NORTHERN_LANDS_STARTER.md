# Northern Lands starter foundation

This repository now uses Unity Technologies' Boss Room v3.0.0 as the
free, complete RPG starter foundation.

The original capsule-only smoke-test remains available in Git history.
The current project includes real characters, animation, classes,
abilities, enemies, dungeon scenes, UI, and a boss encounter.

Source: https://github.com/Unity-Technologies/com.unity.multiplayer.samples.coop
