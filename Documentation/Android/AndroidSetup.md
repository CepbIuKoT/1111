# Android — исходные настройки

## Цель

- IL2CPP;
- ARM64;
- Android API 26 минимум;
- горизонтальная ориентация;
- 30 FPS на минимальном устройстве, 60 FPS на более мощном;
- автономная работа без аккаунтов и серверов.

## Первый тест устройства

1. Применить `Tools → Northern Lands → 3. Apply Android Defaults`.
2. Переключить Build Profile на Android.
3. Включить Developer Options и USB debugging на телефоне.
4. Собрать Development Build с Autoconnect Profiler.
5. Проверить ввод, паузу, сворачивание, блокировку экрана и восстановление сохранения.

## Бюджет вертикального среза

| Ресурс | Начальная цель |
|---|---:|
| Частота кадров | стабильные 30 FPS минимум |
| Активные обычные враги | до 8 рядом с игроком |
| Динамические источники света с тенями | 1 |
| Материалы одного простого врага | 1–2 |
| Размер общей текстуры персонажа/врага | начать с 1024–2048 |
| Постоянные выделения памяти в Update | 0 B |

Пороговые значения уточняются после первой сборки на реальном минимальном телефоне.
