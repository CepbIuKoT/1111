# Unity Build Automation — Android development APK

Этот проект подготовлен так, чтобы первая Android-сборка создавалась в облаке
без локального Unity Editor и без импортированных платных ассетов.

## Репозиторий

- GitHub: `CepbIuKoT/1123` (временно, затем можно переименовать);
- ветка: `main`;
- корень Unity-проекта: корень репозитория;
- Unity: `6000.3.0f1`;
- платформа: Android.

## Конфигурация Build Automation

1. Создать Android build configuration для ветки `main`.
2. Выбрать Unity `6000.3.0f1` и Android.
3. В **Advanced Settings → Script hooks → Pre-Export Method** указать:

   `NorthernLands.Editor.CloudBuildHooks.PreExport`

4. Формат первой тестовой сборки: APK, Development Build.
5. Сцену вручную указывать не обязательно: pre-export метод создаёт
   `Assets/_NorthernLands/Scenes/90_CombatSandbox.unity` и включает только её.
6. Запустить сборку и сохранить build log вместе с APK.

## Что делает pre-export метод

- создаёт недостающие папки проекта;
- применяет Android-настройки;
- пересоздаёт автономную боевую песочницу без окон подтверждения;
- включает песочницу единственной стартовой сценой;
- устанавливает идентификатор `com.northernlands.game`;
- подготавливает версию `0.2.0` (`versionCode` 2).

## Границы первой сборки

Первая APK использует временного персонажа-капсулу, простое окружение, мобильный
HUD и трёх тренировочных противников. Starter Assets, модели, анимации, большая
карта, квесты и полноценный AI будут добавляться после подтверждения рабочего
облачного цикла «изменение → сборка → установка на телефон → отчёт об ошибках».
